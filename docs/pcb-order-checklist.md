## Gate 1: ChatGPT Desktop互換PoC

PCBを設計する前に、手持ちのXIAO単体でホスト連携を成立させます。ここが失敗すると基板上のLED構成やキーの役割が変わるため、最優先です。

- [ ] 使用するZephyrまたはnRF Connect SDKのバージョンを決める
- [ ] XIAO nRF52840の最小プロジェクトをビルド・書き込みできる
- [ ] BLE Device Name、Manufacturer、VID/PID、PnP情報を設定する
- [ ] Vendor Defined Usage Page `0xFF00`、Report ID `6`を実装する
- [ ] 63バイトInput／Output Reportを送受信する
- [ ] JSONの分割、再構成、改行終端を実装する
- [ ] macOSとBLEペアリングできる
- [ ] ChatGPT DesktopにCodex Microとして認識される
- [ ] `sys.version`へ応答する
- [ ] `device.status`へ応答する
- [ ] `v.oai.thstatus`を受信できる
- [ ] `AG00`の押下・解放が認識される
- [ ] 既知のCommand Keyの押下・解放が認識される
- [ ] `ACT11`を試し、13個目のキーとして使えるか記録する
- [ ] エンコーダーの左右・押下イベントを仮入力から送信できる
- [ ] ジョイスティックの上下左右イベントを仮入力から送信できる
- [ ] 切断後に再接続できる
- [ ] HID descriptor変更後の再ペアリング手順を確認する
- [ ] macOS、ChatGPT Desktop、SDK、ファームウェアのバージョンを記録する

### 完了条件
